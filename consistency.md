# consistency.md

Лабораторная работа № 6. Задание 4. Проверка согласованности диаграммы классов и диаграммы последовательности.

## Правило 1: сообщение это операция

| Сообщение (вызов) | Получатель | Есть такая операция? | Что решили |
| --- | --- | --- | --- |
| найтиСвободные | СервисБронирования | Нет, класса нет на схеме | Добавить класс СервисБронирования |
| получитьЗанятость | Расписание | Да (getOccupancy) | Перевести имя для единообразия |
| свободна | Аудитория | Да (isAvailable) | Привести к одному параметру «интервал» |
| создатьБронь | СервисБронирования | Нет | Добавить операцию в СервисБронирования |
| пересекаетсяС | Бронь | Да (overlapsWith) | Перевести имя для единообразия |
| сохранить | ХранилищеБроней | Нет, класса нет на схеме | Добавить класс ХранилищеБроней |
| отправить | СервисУведомлений | Нет, класса нет на схеме | Добавить класс СервисУведомлений |

| Участник | Есть на вашей схеме? | Класс, актёр или пропущенная сущность |

## Журнал согласованности

| № | Расхождение | Решение |
| --- | --- | --- |
| 1 | Сообщения найтиСвободные и создатьБронь адресованы классу СервисБронирования, которого не было на схеме. | Добавить класс координатор с этими операциями. Без него некому выполнять поиск и создание брони. |
| 2 | Сообщение сохранить адресовано ХранилищеБроней, отсутствующему на схеме. | Добавить класс с операцией сохранить(бронь). Хранение вынесено отдельно от самой Брони. |
| 3 | Сообщение отправить адресовано СервисУведомлений, отсутствующему на схеме. | Добавить класс с операцией отправить(сотрудник, бронь). Рассылка не обязанность Брони. |
| 4 | Имена операций получитьЗанятость, свободна, пересекаетсяС не совпадали буквально с исходными английскими названиями. | Переименовать все операции на русский, как в сообщениях. |
| 5 | Сигнатура Аудитория.свободна принимала два параметра вместо одного. | Один параметр «интервал», как в сообщении диаграммы. |

После правок диаграмма классов пересохранена: добавлены СервисБронирования, ХранилищеБроней, СервисУведомлений, операции переименованы на русский.
